# RBCIA workspace notices

Implemented on `feature/veritas-v2` for `http://127.0.0.1:8000/notices`.

The isolated `database/veritas_demo.sqlite` contains 15 new notices: 10 Published, 3 Draft and 2 Archived. Ten are general announcements; five reference existing clients by their stable client codes and require an existing assignment. Existing client names and assignments are preserved.

`DemoNoticeSeeder` is included in both initial and repeat `DemoDataSeeder` runs. It retains the existing demo database guard and workspace marker requirement. Notices are created through `NoticeController`, including authorization, validation, publication and archive audit events. Drafts have no publication date; published and previously published archived notices retain the publication date generated by the normal workflow.

An append-only `demo.notice.seeded` audit event identifies each seed item independently of its editable title. Repeat runs preserve renamed, edited, archived and soft-deleted records. Case-insensitive title checks also preserve pre-existing notices with matching titles. No permissions, assignments or notification behavior were changed.

The Notices views retain the shared design system, with scoped table sizing and wrapping, consistent button minimum heights, a larger editing area, readable body line spacing, search guidance and accessible column headers. Narrow screens scroll the table within its container.
